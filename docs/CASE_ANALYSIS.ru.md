# Аналитические основания SignalDesk

Расчёты для презентации решения, 25 октября 2026 года. Это описательная аналитика переданных организатором файлов, не исследование всего российского крупного бизнеса. Полные исходные CSV не опубликованы. Агрегаты и SHA-256 оригиналов сохранены в [case-analysis-summary.json](../data/case-analysis-summary.json).

## 1. Источники и метод

- Постановка кейса «Новостная аналитика для принятия бизнес-решений», страницы 4–11: крупный бизнес, роли ЛПР, персонализация, использование материалов банка, агентная логика и проверяемость выводов.
- [Папка данных организатора](https://drive.google.com/drive/folders/1Ep8wWoEHTg5Q8kwrLx2j_xFyxGUEVxFq): `df_Uid_data_hack.csv`, `df_Uid_payment_hack.csv`, `df_Fid_Uid_link_hack.csv`.
- [Материалы банка](https://drive.google.com/drive/folders/15xZTLF1lZ65p6o5xpNA_fRbxjoV-UlG1): девять отчётов; оригинальные даты и страницы сохранены в `data/bank/`.
- Переданный Q&A вебинара: выручка — 2025 год, рубли, юрлицо; значение 1000 — пропуск; город обслуживания не устанавливает рынок; смысл платежа не устанавливает роль контрагента. [Применённые уточнения](WEBINAR_INSIGHTS.ru.md).

Файлы прочитаны полностью как UTF-8 CSV с разделителем `;`. Число строк не равно числу уникальных компаний. Для сегментного среза используются только CLIENT с однозначным ID и выручкой юрлица строго больше 15 млрд рублей. Повторяющиеся ID исключаются целиком. Сегмент по неполному составу группы не восстанавливается. Суммы переводов складываются в Decimal; переводы между одинаковыми ID выделяются отдельно. Признаки кредитов, лизинга и внешней торговли не взаимоисключающие.

Вывод для решения: сумма наблюдаемых переводов не должна автоматически превращаться в оценку закупок, выручки или зависимости от поставщика. Переводы себе исключаются из внешних связей; неизвестный участник не получает выдуманную отрасль. Этот вывод основан на структуре предоставленного набора, не на предположении о реальной экономике компаний.

## 3. Стартовый срез финансовой повестки

В переданном наборе 102 действующих юрлица с однозначным ID и известной выручкой более 15 млрд рублей за 2025 год. Это удобный срез для проверки финансового сценария, а не весь крупный бизнес и не все группы кейса.

| Признак | Число из 102 | Доля |
|---|---:|---:|
| Кредитный продукт | 48 | 47,1% |
| Лизинг | 67 | 65,7% |
| Внешняя торговля | 55 | 53,9% |
| Кредит или лизинг | 80 | 78,4% |

Вывод для решения: финансовому директору полезно связать макроэкономическую новость с подтверждённым наличием финансирования. При этом флаги продуктов не раскрывают остатки, фиксированную/плавающую ставку, срок погашения или валютную позицию. Эти условия сервис запрашивает явно, вместо расчёта выдуманного денежного эффекта.

## 4. Основания для проверки AI-выводов

Dell’Acqua et al., [Navigating the Jagged Technological Frontier, HBS Working Paper 24-013](https://www.hbs.edu/ris/download.aspx?name=24-013.pdf), 2023: рандомизированный эксперимент с 758 консультантами BCG. В задачах в пределах возможностей GPT-4 участники выполняли задания на 25,1% быстрее. В задаче за пределами возможностей модели вероятность правильного решения снизилась на 19 процентных пунктов. [Обзор авторского института](https://aiinstitute.hbs.edu/navigating-the-jagged-technological-frontier/). Это результат исследования другой модели и другой работы, не оценка SignalDesk и не прогноз его эффекта.

[NIST AI 600-1](https://doi.org/10.6028/NIST.AI.600-1), 2024, §2.2: генеративная модель может уверенно формулировать ложные сведения, логику и ссылки. Для SignalDesk из этого следуют сохранение первоисточников, независимая проверка, структурные ограничения, маркировка неопределённости и регулярная экспертная оценка. Одна проверяющая модель не гарантирует достоверность.

## 5. Проверка на конкретном событии

- Клиент U_88715: производство электрооборудования, выручка юрлица 25 462 847 642 рубля за 2025 год, признаки кредитов и лизинга.
- Новость: [решение Банка России от 23.10.2026](https://www.cbr.ru/press/PR/?file=23102026_133000key.htm) о сохранении ключевой ставки 14%.
- Экспертный контекст: [обзор Альфа-Банка от 11.09.2026](https://drive.google.com/file/d/1shHG89LtMgHT1_uEebHmQSFZe_zbeq7-/view), страница 1. Он явно датирован и используется как исторический контекст, не текущая новая рекомендация банка.
- Персональная интерпретация: новое финансирование и рефинансирование остаются дорогими; изменение платежей по действующему долгу зависит от договора.
- Проверяемое действие: уточнить структуру фиксированных/плавающих ставок и график погашения, затем оценить чувствительность денежного потока. Денежный ущерб без остатков и условий долга не вычисляется.

## 6. Воспроизведение расчётов

```bash
python3 scripts/analyze_case_dataset.py \
  --companies /path/to/df_Uid_data_hack.csv \
  --payments /path/to/df_Uid_payment_hack.csv \
  --people-links /path/to/df_Fid_Uid_link_hack.csv \
  --output output/case-analysis.json
```

Этот отдельный офлайн-расчёт читает полные исходные файлы. Он не означает, что прототип загружает все 1,38 млн переводов через интерфейс: для UI действует лимит 2 000 строк на CSV, а проверочный рабочий клиент использует ограниченный импорт. Размеченная экспертами точность и бизнес-эффект пилота ещё не измерены.
